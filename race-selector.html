🔧 How the Framework Works

The Model Grand Prix framework is now fully reusable! You can create unlimited custom races using the same powerful 3D visualization, stunts, cameras, and audio system.

To create a custom race:

1. Copy any existing race HTML file (like gemini-vs-deepseek.html)

2. Modify the window.customCompanies and window.customModels objects with your data

3. The framework automatically adapts the cars, colors, and timeline to your data

Data structure:

Each company needs: name, color, number, and current model ID. Each model needs: id, name, company, date, scores, and summary.

All original features (3D race, stunts, cameras, audio, replay) work automatically with your custom data!
