# Archive

Superseded copies of core files, kept only as a quick point-in-time reference
from earlier stages of development (before garage sequence rework, fullscreen
rework, etc.). These are **not loaded by any page** and are not needed to run
the project — the working versions live under `../src/`, `../styles/`, and
`../races/`.

Safe to delete; the full history is also available via `git log`.
